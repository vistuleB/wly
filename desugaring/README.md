A collection of utilities for transforming
[VXML](https://github.com/vistuleB/wly/tree/main/vxml) through composable
desugaring pipelines, then splitting and emitting the result as one or more
target documents such as HTML or JSX.

Writerly-specific defaults live in `writerly_defaults`, which adapts
[Writerly](https://github.com/vistuleB/wly/tree/main/writerly) assembly,
parsing, and emitting to the generic renderer.
